# ClawBio Skill Library — Domain Report

**100 skills across 14 domains.** 50 registered, 50 agent-readable.

Generated by `scripts/generate_skills_summary.py` from the live skill registry in `clawbio/cli.py` and the domain taxonomy in `scripts/skill_domains.json`. Do not edit by hand — rerun the script.

**Tier key:** **[R]** registered, runnable via `clawbio run <skill>` · **[A]** agent-readable, SKILL.md methodology only

## 1. Clinical genomics & variant interpretation — 15 (7R / 8A)

The library's largest domain.

**[R]**

- `pharmgx` — Pharmacogenomics reporter (12 genes, 31 SNPs, 51 drugs)
- `clinpgx` — ClinPGx API query (gene-drug interactions, CPIC guidelines, drug labels)
- `drugphoto` — Drug photo analysis (single-drug PGx lookup from photo identification)
- `nutrigx` — Nutrigenomics advisor (diet, vitamins, caffeine, lactose)
- `acmg` — ACMG/AMP clinical variant classifier (28-criteria, SF v3.2 screening)
- `cnv-acmg` — CNV/SV ACMG classifier (ClinGen 2019 / Riggs 2020 dosage point framework)
- `profile` — Unified personal genomic profile report

**[A]**

- `variant-annotation` — Annotate VCF variants with Ensembl VEP REST, ClinVar significance, gnomAD/population frequency context, and prioritized variant ranking.
- `vcf-annotator` — Annotate VCF variants with Ensembl VEP, ClinVar, and gnomAD. Ranks variants by impact (HIGH/MODERATE/LOW/MODIFIER) and generates a reproducible report.
- `clinical-variant-prioritizer` — Screen a genotype set (array or WGS-derived) against OMIM-morbid, ACMG-SF and Hereditary-Cancer gene panels and prioritise carried variants by ClinVar significance, gnomAD frequency, inheritance model and zygosity, following the pathogenicity-screening method of Corpas et al. 2021 (Whole Genome Interpretation for a Family of Five).
- `rare-high-impact-variants` — Count rare, high-impact loss-of-function variants carried in a VCF, annotated with molecular consequence and population allele frequency
- `hla-typing` — HLA allele typing from WGS/WES VCF data
- `wes-clinical-report-en` — Generates professional clinical PDF reports in English from WES (Whole Exome Sequencing) data with clinical interpretation summary, pharmacogenomic alerts, and follow-up recommendations.
- `wes-clinical-report-es` — Generates professional clinical PDF reports in Spanish from WES (Whole Exome Sequencing) data with clinical interpretation, pharmacogenomic alerts, and follow-up recommendations.
- `drug-photo` — Medication photo to personalised PGx dosage card via Claude vision — snap a pill, get genotype-informed guidance

## 2. GWAS, PRS & statistical genetics — 12 (10R / 2A)

Deepest runnable coverage in the library.

**[R]**

- `gwas` — GWAS Lookup — federated variant query across 9 genomic databases
- `gwas-pipe` — GWAS pipeline — PLINK2 QC + REGENIE two-step association (Manhattan, QQ, lead variants)
- `prs` — GWAS Polygenic Risk Score calculator (PGS Catalog, 3000+ scores)
- `just-prs` — Evidence-aware VCF/WGS PRS through a pinned local just-prs MCP server
- `mr` — Mendelian Randomisation — two-sample MR with IVW, Egger, weighted median/mode + full sensitivity
- `gwas-region` — GWAS Catalog region fetch — tabix-on-FTP harmonised summary stats per genomic window
- `eqtl-region` — eQTL Catalogue region fetch — tabix-on-FTP cis-QTL summary stats per genomic window
- `ld-region` — 1000G LD region compute — plink 1.9 r² between a lead and partners in a region for one super-population
- `ukb-ppp-region` — UKB-PPP region fetch: per-variant plasma cis-pQTL summary stats per genomic window (Sun 2023, Synapse-backed)
- `locuscompare-region` — LocusCompare regional diagnostic — 4-panel coloc visualisation (Liu 2019) for one (eqtl × gwas) pair

**[A]**

- `fine-mapping` — Statistical fine-mapping of GWAS loci using SuSiE, SuSiE-inf, and Approximate Bayes Factors to identify credible sets and posterior inclusion probabilities (PIPs) for causal variant discovery. SuSiE-inf adds an infinitesimal polygenic component for improved calibration at well-powered loci.
- `wgs-prs` — End-to-end WGS to polygenic risk score pipeline. Takes paired-end FASTQ files (or a pre-existing VCF) through nf-core/sarek for variant calling, applies VCF QC (normalisation, hard filtering, Ti/Tv and Het/Hom checks), then computes polygenic risk scores via the PGS Catalog. Fills the FASTQ to VCF gap upstream of the gwas-prs skill.

## 6. Gene regulation — Genomic Intelligence suite — 6 (0R / 6A)

Entirely agent-readable; all six call one hosted API, so an outage removes the whole domain.

**[A]**

- `gi-annotation` — Predict gene and transcript structure (intervals, exons, strand) from a DNA sequence using the Genomic Intelligence DNA Annotation model, via the hosted /v1/tasks/annotation/predict API. Submitted asynchronously — the pipeline takes ~20 s for ~20 kbp.
- `gi-promoter` — Detect promoter regions in DNA sequences using the Genomic Intelligence G0 transformer (GENA-LM BERT Large), via the hosted /v1/tasks/promoter/predict API. Returns per-window promoter probabilities and called regions.
- `gi-splice` — Detect splice donor and acceptor sites in DNA sequences using the Genomic Intelligence G0 BigBird transformer, via the hosted /v1/tasks/splice/predict API. Returns per-position site probabilities and called sites.
- `gi-enhancer` — Predict enhancer activity in DNA sequences using the Genomic Intelligence G0 DeepSTARR model, via the hosted /v1/tasks/enhancer/predict API. Returns per-window activity scores.
- `gi-expression` — Predict tissue / cell-type expression (log TPM + TPM) from a 9,198–500,000 bp TSS-centered DNA sequence (longer than one 9,198 bp window needs --tss-index) using the Genomic Intelligence G0 Expression model, via the hosted /v1/tasks/expression/predict API. The model is conditioned on a free-text cell-type / assay description.
- `gi-chromatin` — Predict chromatin state — histone marks, DNase, TF binding — across 919 tracks (DeepSEA-style) for DNA sequences, via the hosted Genomic Intelligence /v1/tasks/chromatin/predict API.

# Cross-cutting findings

## Registered skills with a missing script

- `llm-bench` — `llm_biobank_bench.py` not found in `skills/llm-biobank-bench/`

49 of 50 registered scripts resolve on disk.

## The registration gap

44 of 50 agent-readable skills ship a Python script but have no entry in the `SKILLS` dict in `clawbio/cli.py`, so they cannot be reached through `clawbio run`.

That is 44% of the library's implemented functionality.

Genuinely spec-only (6): `bgpt-mcp`, `claw-semantic-sim`, `de-summary`, `drug-photo`, `ncbi-datasets`, `repro-enforcer`.

## Coverage asymmetry

Fully runnable domains: Single-cell & spatial.

Domains with no CLI path at all: Gene regulation — Genomic Intelligence suite, Synthetic genomics & simulation, Cancer, imaging & structure.

## Duplicate pairs worth consolidating

- `variant-annotation` <-> `vcf-annotator` — both VEP + ClinVar + gnomAD with impact ranking; strongest merge candidate
- `drug-photo` [A] <-> `drugphoto` [R] — same capability split across tiers
- `proteomics-clock` <-> `organ-aging-studio` — same Goeminne clock, different presentation
- `bioqc` <-> `multiqc-reporter` — overlapping MultiQC aggregation
- `phylo` <-> `fastreer` — both tree building, different engines (arguably complementary)
- `wgs-prs` <-> `prs` — genuinely additive; `wgs-prs` supplies the FASTQ-to-VCF stage `prs` lacks

## Other observations

- Naming conventions drift: `claw-` prefixes, `gi-` prefixes, `-region` suffixes, and bare names coexist without a clear rule.
- The four regional-fetch skills (`gwas-region`, `eqtl-region`, `ld-region`, `ukb-ppp-region`) share tabix-on-FTP access to external hosts.

## Drift against `skills/catalog.json`

The catalog indexes 97 skill folders; this report covers 100 list entries. The two counts differ by design — the catalog is keyed on folders and applies `EXCLUDED_FOLDERS`, while the CLI is keyed on aliases.

Folders present here but absent from the catalog: `llm-biobank-bench`, `wes-clinical-report-es`.
