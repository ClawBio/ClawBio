# snp-phewas catalogs

Metadata only: outcome lists and an outcome mapping. No association statistics.

| File | Rows | Built from | Terms |
|---|---|---|---|
| `pan_ukbb_outcomes.tsv.gz` | 7,223 | Pan-UK Biobank phenotype manifest, release 2024-06-26 (md5 `0735065d06ea8ffb098c119ef419c821`) | CC BY 4.0 |
| `finngen_r12_outcomes.tsv.gz` | 2,469 | FinnGen R12 manifest (md5 `3034fcfbf61bb1ba33a0efb3a36ac482`) | FinnGen public results terms |
| `biobank_outcome_crosswalk.tsv.gz` | 9,692 | the two manifests above plus FinnGen's R12 phenotype-mapping files (md5s in `snp_phewas_crosswalk.SOURCES`) and the ICD-10 block structure | derived; FinnGen and Pan-UK Biobank acknowledgments below |

The two outcome catalogs are regenerated by `snp_phewas_build_catalogs.py`, which refuses a
manifest whose md5 differs from the pin in `datasets.yaml`.
